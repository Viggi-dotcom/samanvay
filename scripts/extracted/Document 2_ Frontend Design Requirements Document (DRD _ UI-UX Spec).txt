4. Accessibility & Usability Standards
● Contrast Compliance: All text-to-background contrast ratios strictly meet WCAG 2.1
Level AA standards: minimum 4.51 for normal body text and 31 for graphical UI
components and large text.
● Touch Targets: All interactive elements provide a minimum bounding box of 44 x 44
pixels on touch-enabled tablet and mobile interfaces.
● Keyboard Navigation: Full Tab Order navigation enabled. Every interactive node
contains an explicit focus ring (focus-visible: 2px solid --primary-500;
outline-offset: 2px). Map pan/zoom supports standard arrow keys (+, -, and arrow
keys).
● Screen Reader Semantic Roles:
○ Dynamic live metrics marked with aria-live="polite".
○ Anomaly banners flagged with role="alert".
○ Expandable evidence drawers linked with aria-expanded="true/false" and
aria-controls="evidence-panel-id".
